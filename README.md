# MT1-LABECAM

Employee Task Management Web Application built for the MT1 Node.js lab examination.

## Repository link

`https://github.com/ayushmanshukla362/MT1-LABECAM` 

## Run

```bash
npm install
npm run http       # http://localhost:3000
npm run express   # http://localhost:4000
```

The HTTP-module server and Express server are independent, use only JavaScript arrays, and do not use a database.

## Structure

- `httpServer.js` - built-in `http` and `fs` modules, port 3000
- `expressApp.js` - Express CRUD REST API, port 4000
- `public/index.html` - static page served by `/home`
- `copy/` - first-page copy and API calling details
- `screenshots/` - verification evidence for the exam submission
